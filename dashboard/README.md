# Bazar Shodai admin dashboard

Admin and staff panel for Bazar Shodai (বাজার সদাই), built with Vite, React and Tailwind CSS.

```bash
cp .env.example .env   # then fill it in
npm install
npm run dev            # http://localhost:5173
```

Needs the API from `../server` running. Set `VITE_API_URL` in `.env`.

Useful scripts: `npm run build` (type-check + production build), `npm run lint`.
See the project plan in [../PLAN.md](../PLAN.md).
